# شركة الربيع — مكتبة ألعاب PS4

نسخة Static جاهزة للرفع على GitHub Pages.

## محتوى المكتبة
- **296 عنوانًا فريدًا** بعد مراجعة القوائم المصورة وإزالة التكرارات.
- تم دمج النسخ/التحديثات/الـDLC الخاصة باللعبة الواحدة كعنوان واحد بدل تكرارها.
- تم أيضًا إزالة التكرارات الموجودة في النسخة السابقة مثل Days Gone وDeath Stranding.
- الصور تُجلب تلقائيًا كصور أغلفة حقيقية من Wikipedia/Wikimedia عند فتح الموقع.

## التشغيل
1. ارفع الملفات إلى Repository على GitHub.
2. من Settings → Pages اختر Deploy from branch.
3. اختر `main` و`/ (root)`.
4. افتح رابط GitHub Pages.

لا يوجد Build ولا npm ولا Server.

## ملاحظة
بعض القوائم المصورة تحتوي على ألعاب Classics/PS2 تعمل على PS4، لذلك أُدرجت كعناوين Classics بدل اعتبار ملفاتها المتعددة ألعابًا منفصلة.


### تدقيق القوائم
تمت إعادة مراجعة الصور المستلمة وإضافة العناوين التي كانت ناقصة في النسخة السابقة، مع دمج الـUpdates والـDLC والملفات المتعددة تحت اللعبة الأصلية وعدم عرضها كألعاب مستقلة. أُضيفت كذلك مجموعة Resident Evil التي أكد المستخدم توفرها لديه.


### تدقيق أخير
تمت مراجعة الصور والقائمة مرة أخرى، وعدم اعتبار الـUpdate والـDLC والتكرارات ألعابًا مستقلة. تمت إضافة عناوين PS4 إضافية حتى أصبحت المكتبة 350 عنوانًا فريدًا.
